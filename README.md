# 🏥 医院预约导航 · 医药代表版

一个给医药代表用的单页工具：**医院入口快速跳转** + **拜访排班表**。
纯前端、零依赖、可离线、支持暗色模式、可加到手机桌面。

在线访问：**https://752676416-dev.github.io/rep-nav/**

---

## 功能

### 一、入口导航（核心）

自己录入常用入口，五种类型：

| 类型 | 点击行为 | 典型用途 |
|:---|:---|:---|
| 🌐 网页 | 直接跳转 | 医院预约挂号页 |
| 💚 小程序 | 弹出小程序码（长按识别直接进）／无码时给复制指引 | 佛山Plus 等 |
| 📞 电话 | 直接拨号 | 药库、科室电话 |
| 🗺️ 导航 | 跳高德地图搜索该名称 | 找医院、找药库 |
| 📋 复制文本 | 复制内容 | 账号密码、地址 |

- **点击**卡片 → 打开
- **长按**卡片 → 打开 / 复制链接 / 编辑 / 删除
- 支持**小程序码**：上传后点卡片弹大图，长按「识别图中小程序码」直接打开
- 顶部搜索框按名称／备注过滤

### 二、拜访排班表

- 一周一行，**每天分上午 / 下午**两个时段
- 每个时段可填：**拜访单位**（下拉选已录入的入口，也可手填）+ **姓名**（拜访对象）+ **拜访目的**
- 今天整行高亮；支持上周 / 下周翻页，各周独立保存
- **复制排班** → 生成文本直接发主管
- **套用上周** → 一键复制上周排班（跑固定路线省事）
- **清空本周** → 只清当前这一周

### 三、其他

- **暗色模式**：右上角按钮三态循环（跟随系统 / 深色 / 浅色）
- **PWA**：可添加到手机桌面，断网也能打开
- 数据全部存在**本机浏览器**（localStorage），不上传任何服务器

## 使用须知

### 小程序为什么不能直接跳转？

微信不允许网页直接拉起小程序。官方只有两条路，且都要求**你是该小程序的管理方**：

| 方案 | 能否直跳 | 门槛 |
|:---|:---|:---|
| `<wx-open-launch-weapp>` 开放标签 | ✅ | 需认证服务号 + HTTPS 备案域名 + 后端签名 + 小程序已关联 |
| URL Link（`wxaurl.cn`） | ✅ | 需用该小程序的 access_token 生成，只有管理员能做 |
| **长按识别小程序码** | ✅ | **零门槛，任意小程序都行** ← 本项目采用 |

对佛山Plus 这类第三方小程序，前两条走不通，所以用「小程序码 + 长按识别」，体验接近直跳。

> 如果你有自己小程序的官方 URL Link（`wxaurl.cn` 开头），直接存成「网页」类型即可点击直跳。

### 数据备份提醒

数据存在本机浏览器，**清理微信/浏览器缓存会清空数据**。建议定期用「长按卡片 → 复制链接」把重要入口备份到微信收藏。
